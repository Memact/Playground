# Community Context Brief

Community Context Brief is a Memact Playground feature for apps and platform bots.

It summarizes approved community memory without exposing raw private activity.

It can help:

- Discord bot onboarding
- Reddit community assistants
- Telegram group helpers
- app community personalization

The feature only uses provided approved summaries, allowed Wiki context, platform metadata, and topic signals. It does not infer sensitive traits, classify people, or summarize private messages unless that information was explicitly approved and already summarized before it reaches the feature.
