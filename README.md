# Memact Playground

> Playground is retired from the current Memact core direction.
>
> Current contributor work has moved to Schema, where app category schemas define what context matters for each type of app.
>
> Playground is kept as an archived feature-runtime experiment from an earlier Memact direction.

Playground was where Memact features were built and tested.

Current Memact is centered on a user-controlled context layer for app personalization.

Apps send context. App categories give it shape. Wiki gives users control.

Current core repos are Access, Wiki, Schema, Memory, Contracts, SDK, and Website.
